No AI inside, and how to check

Clear45 does not call any AI service. The reading and writing happen in the customer’s own Claude. This app only checks, saves, calculates and displays.

Who does what

JobDone by
Reading the invoice (supplier, dates, amount, Udyam number)The customer’s Claude
Asking the user for anything the invoice does not sayThe customer’s Claude
Writing summaries and notes for the finance headThe customer’s Claude
Checking the fields and refusing bad valuesClear45, fixed rules
Working out the legal due date and the countdownClear45, fixed rules (lib/rules.js)
Saving bills, edits, approvals and the activity logClear45, Postgres database
Building the bill register and the MSME-1 working sheetClear45, fixed rules

Everything the app is built from

  • Node.js: runs the server code. Only its built-in modules are used.
  • pg: the standard driver that talks to the Postgres database. This is the only package installed (see package.json).
  • Postgres on Neon: the database.
  • Vercel: hosts the pages and runs the server code.
  • Plain HTML, CSS and JavaScript in the browser. No frameworks.

The Claude connection is a small MCP server written by hand in lib/mcp.js. MCP (Model Context Protocol) is the standard that lets Claude call actions in another app. The server answers Claude’s calls; it never calls Claude or any other AI.

Three ways to check

  1. Open package.json in the code repository. The only dependency is pg.
  2. Search the repository for openai, anthropic, gemini, langchain or api. web addresses. The only matches are on this page and in the README, where the words are named.
  3. Look at the hosting settings. The only secrets are the database address, the connector key and the demo login. There is no AI key.

Data kept

Supplier name, PAN, GSTIN, Udyam number, invoice number, dates, amount, payment terms, notes and the activity log. Clear45 does not store the invoice file or any bank account number.

Clear45 is a decision-support tool, not tax or legal advice.
